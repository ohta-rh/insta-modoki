# Web 版の画面の参照値と今のアプリとの差

ADR-0003 の線引きを守る。この文書には参照先の名前・ロゴ・アイコンの形・画像・画面写真を載せない。載せるのは寸法・比率・文字の大きさと太さ・中立色の値と、構成と振る舞いの言葉での説明だけ。以下、参照先を「参照」と書く。

## 1. 方法と出典

| 項目 | 内容 |
|---|---|
| 日付 | 2026-11-23 |
| 参照の測り方 | Playwright 1.65（`channel: 'chrome'`、headless、使い捨てのプロファイル、`locale: ja-JP`）。ログインしない。読み込みは 5 回だけ: ログイン画面、公開のブランドのプロフィール、そこから辿れる公開の投稿 1 件、`/explore/`、登録画面。各要素の `getBoundingClientRect` と `getComputedStyle`、`:root` の CSS 変数（1178 個）を JSON に取った。画面写真は scratchpad にだけ置き、リポジトリには入れない |
| 幅 | 1280px・1100px（参照のナビの境目 1264px より下）・375px（高さ 812px） |
| 今のアプリの測り方 | worktree `ui-research`（origin/m3/phase2 = b6fc24a）を slot 4（ポート 3104）で `pnpm build` → `pnpm start`、`seed --profile demo`（30 人・300 投稿）、デモアカウントでログインして同じ方法で 1280・1024・375px を測った。測定後 `slot.mjs drop 4` |
| 出典の書き方 | 「実測 <画面> <幅>」= 上の方法で測った値。「変数 `--x`」= 参照の `:root` に定義された CSS 変数の値（参照自身が持つ設計値。ログイン後の画面にも使われる共通の値）。「未確認」= 公開ページで見えず、書かれた出典も見つからなかったもの |
| 限界 | ログイン後だけの画面（ホームのフィードと左ナビ、右の「おすすめ」列、ストーリーの列、フィードのカード、検索と通知の横パネル、投稿作成のモーダル、DM）は直接見えない。公開ページは左ナビの代わりに高さ 60px の上部バーを出す。プロフィールと投稿は登録を促すダイアログ（548×491px、角丸 32px、背景 `rgba(12,16,20,.7)`）が重なるが、後ろの DOM はそのまま測れる。`/explore/` はログインしていないと「人気のコンテンツ」の案内ページで、ログイン後の探索グリッドではない。書かれた出典の検索（2026-11-23）では、具体的な px を書いた信頼できる解説は見つからなかった（[TechCrunch 2022-11-08](https://techcrunch.com/2022/11/08/instagram-is-updating-its-web-interface-to-take-advantage-of-large-screens) は左ナビの導入と広い画面への対応を書くが、数値は無い。[userstyles.world #7842](https://userstyles.world/style/7842) はフィード幅 470px を前提にしている）。そのため、ログイン後の画面は参照の CSS 変数を主な出典にし、変数でも決まらない値は「未確認」とした |

## 4. 自前に残すもの、それでも近く見せる方法

- **名前とロゴ**: 「Mado（仮称）」と窓の印のまま。72px のナビでは印だけ、244px では印＋ワードマーク（高さ 26〜29px に合わせる）。参照のワードマークの書体に似せない。
- **アイコン**: 自作のまま。近く見せる要点は形ではなく作り方: 24px の格子、線の太さ 2px 前後（今は 1.5。参照の線は 24px で太めに見える。値は未確認）、角の丸い線の端、輪郭だけ＝ふだん、塗りつぶし＝今の項目・押した状態（ホーム・探索・通知・保存・いいね）。足すもの: 「その他」（3 本線）、グリッド、送る、ストーリーの次へ。参照の形を写さない。
- **ストーリーの輪**: 形は同じ（2px の輪＋2px の白い隙間、外径 66px、未読のとき色、既読は `#DBDBDB` 1px）。色は参照の黄〜橙〜赤紫の傾き（トレードドレス）ではなく、自前の `--gradient-window`（ティール → 青 → インディゴ）。
- **いいねの赤・通知の点**: 赤い色そのものは一般的だが、参照と同じ `#FF3040` に固定せず自前のコーラル寄りの赤を図形にだけ使う（3:1 以上）。
- **主の色**: 参照の青（`#4A5DF9`）ではなく自前のインディゴ（`#4F46C8`）。色相が近いので、ボタンの形・大きさ・角丸を合わせれば印象は近い。
- **フッター**: 「Meta 社とは関係ありません」の注記は残す（`brand.ts`）。
