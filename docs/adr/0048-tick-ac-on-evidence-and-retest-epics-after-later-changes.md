# ADR-0048: 確かめた AC はその場で issue のチェックを付け、PASS した EPIC の画面に後から触れたら総合試験をやり直す

- ステータス: 採用
- 日付: 2026-11-22
- 決定者: ユーザー（「AC チェックしたら issue の AC にチェックつけろ」「エビデンスつきの総合試験した？」「これらはルールに」）
- 関連: [ADR-0012](0012-epic-integrated-test-in-real-browser.md)、[ADR-0017](0017-milestone-on-an-integration-branch-when-a-pr-is-requested.md)、`.claude/rules/delivery.md` §3・§4・§5・§6

## 背景

- M1 では、32 本の issue（EPIC 7・PBI 25）の DoD にチェックを付け、確かめた結果を issue のコメントに書いた。しかし AC のチェックボックスは 1 つも付けていなかった（2026-11-22 に `gh issue list --json body` で数えて 0 / 332）。DoD の「全ての AC を確かめた」にチェックがあるのに、AC 自体は未チェックに見え、どれを確かめたのかを issue から読めなかった。
- `delivery.md` §4 の手順 3 は「DoD を付ける」とだけ書き、AC のチェックに触れていなかった。
- 2026-11-22、全 EPIC の総合試験が PASS した後に、`/simplify` の作り直し（11 commit、`836c2e6`）を統合ブランチに入れた。触れたのは EPIC #2〜#7 の画面を支えるコードで、Server Action の失敗の扱い、ページ送り、アバターの URL、セッションの確認、フォーカスの閉じ込め、投稿ページの読み込みにあたる。確かめたのは verify（headless の E2E を含む）だけだった。ADR-0012 は、headless の E2E を総合試験として数えない。
- AC の確認方法が名指しするテストを機械で突き合わせると、250 件中 4 件の名前が後の PBI で変わっていた。テストの中身は同じだった。

## 決定

- Director は、AC を書いてある確認方法で確かめたら、**その場でその issue の AC のチェックボックスを付ける**。チェックは確かめた証拠があるときだけ付ける。証拠が無い AC は未チェックのまま残し、DoD の「全ての AC を確かめた」も付けない。
- AC の確認方法が名指しするテストの名前が変わっていたら、チェックを付ける前に、issue の確認方法を今の名前に直す。直したことは、日付を添えた注記で本文の先頭に書く。
- EPIC の総合試験は、レポートで PASS になった AC にチェックを付ける。
- EPIC の総合試験が PASS した後に、その EPIC の画面を支えるコードを変える変更を統合したら、PR を渡す前（ADR-0017 の統合ブランチでは、PR をレビュー待ちにする前）に、**影響する EPIC の総合試験を写真つきでやり直す**。対象は、変更が触れたファイルを使う画面を持つ EPIC 全てとする。verify と headless の E2E は、このやり直しの代わりにならない。
- AC が未チェックの issue は閉じない。そのような issue を含む PR は渡さない。

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| AC にその場でチェックを付け、後から触れた EPIC は総合試験をやり直す（採用） | issue を見れば何を確かめたかが分かる。PR の時点の画面が、写真つきで確かめられている | 統合の手間と、総合試験の時間が増える |
| DoD とコメントだけにする（M1 のやり方） | 手間が少ない | AC が未チェックに見え、どれを確かめたかが issue から読めない |
| 後からの変更は verify だけで確かめる | 速い | ADR-0012 が退けた headless を、総合試験の代わりにすることになる |
| 後からの変更があったら、全 EPIC の総合試験をやり直す | 漏れが無い | 触れていない EPIC にまで時間を使う |

## 結果

- issue の AC のチェックが、確かめた証拠の目印になる。チェックが無い AC は、確かめていないという意味になる。
- PR の時点の画面は、全て写真つきの総合試験で確かめられている。
- コストとして、後から変更を入れるたびに、影響する EPIC の総合試験の時間がかかる。
- 今後は、`delivery.md` §3 の手順 4、§4 の手順 3、§5 の手順 3・5、§6 を守る。
