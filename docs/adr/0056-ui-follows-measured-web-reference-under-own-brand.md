# ADR-0056: UI の値は実測した参照の Web 版に従い、ブランドの色と形は自前のままにする

- ステータス: 採用
- 日付: 2026-11-23
- 決定者: エージェント（委任された判断）
- 関連: #87、#88、[docs/research/web-ui-reference.md](../research/web-ui-reference.md)、[ADR-0003](0003-reproduce-ux-under-own-brand.md)、[docs/architecture/design-system.md](../architecture/design-system.md)

## 背景

- 利用者から「参照の Web 版とまるで見た目が違う」と言われた。調査（`web-ui-reference.md` §2.9・§2.10・§3、2026-11-23）で、本文 14px/18px の黒、補助の文字 `#737373`、罫線 `#DBDBDB`、骨格の幅などを実測した。今のトークンは初期の仮の値（本文 16px、`#111827`、`#e5e7eb` など）のまま。
- ADR-0003 により、他社の名前・ロゴ・アイコン・フォント・画像は使わない。
- 参照のエラーの赤 `#ED4956` は白の上で 3.69:1 で AA に届かない。`#737373` は `#F3F5F7` の上で 4.34:1、`#EFEFEF` の上で 4.12:1 で届かない（`#FFFFFF` の上は 4.74:1、`#FAFAFA` の上は 4.5:1 以上）。
- 参照のタップ領域は 40px で、#46 の検査は 44px 以上を求める。

## 決定

- トークンと骨格の幅・境目は `web-ui-reference.md` §3 の値に従う。`tokens.css` と `tokens.ts` に持ち、`tokens.test.ts` が突き合わせる。
- 主の色（主のボタン・リンク・文字のボタン）は自前のインディゴ `#4F46C8`。ストーリーの輪は自前の `--gradient-window`。いいねの赤は `#F2545B`。
- アイコンは自前のまま、24px の格子・線 2px で描き直す。今の項目と押した状態には塗りつぶしの版を持つ（描き直しは #89 以降）。
- エラー・削除の文字は `#D62D3C`（白の上で 4.88:1）。`--color-danger`。
- 補助の文字 `#737373` は白と `#FAFAFA` の上だけに置く。`#F3F5F7`（surface）・`#EFEFEF`（highlight）の上では `--color-text` を使い、ホバーで面になる要素は `hover:text-text` を足す。`token-usage.test.ts` が全ての `.tsx` を走査して確かめる。
- タップ領域は 44px 以上のまま（#46 の検査を参照の 40px より優先する）。
- `--color-text-muted` は廃止し、`--color-text-secondary` に一本化する。
- Tailwind の既定の `rounded-*` と `--space-*` の番号は変えない。新しい値は名前の重ならないトークン（`--radius-pill` など）で足す。

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| (a) 参照の値を全部採る（主の色・輪の色まで） | 見た目が最も近い | ADR-0003 に反し、他社の色の識別性を写す |
| (b) 寸法と中立色だけ採り、ブランドの色・形は自前（採用） | 骨格と文字が参照と並び、ブランドは自前のまま。コントラストを AA に保てる | 主の色・輪は参照と違う |
| (c) 今の値のまま | 変更が無い | 利用者の指摘（見た目が違う）が残り、後続の画面の直しの土台が無い |

## 結果

- 全ての画面の本文が 14px/18px の黒になり、罫線・補助の文字・エラーの色が参照の値になる。後続の PBI（#89〜#100）は同じトークンの上で画面ごとに寸法を揃える。
- コストは、補助の文字を面の上に置けなくなること（`token-usage.test.ts` が落ちる）。置くときは `text-text` にする。
- 既読のストーリーの輪は、罫線の色では白の上で 3:1 に届かないので、補助のアイコンの色 `--color-icon-secondary`（4.74:1）を使う。
- 今後、色・寸法の値は `tokens.css` と `tokens.ts` だけに持ち、各部品に直書きしない。
