# ADR-0003: Instagram の UX と機能を忠実に再現し、ブランドは独自にする

- ステータス: 採用
- 日付: 2026-11-20
- 決定者: ユーザー（忠実な再現）。ブランドの線引きはエージェント
- 関連: [企画書](../proposal/)、[ADR-0010](0010-independent-code-and-security-review.md)

## 背景

ユーザーの目的は、Instagram を忠実に模倣した Web アプリを作ること。一方で、名前・ロゴ・アイコンのような商標や素材を使うと、権利の問題が出る。リポジトリは GitHub の public リポジトリ。企画書（2026-11-20）は、製品名を「Mado（仮称）」とし、商標を調べてから正式に決める案にしている。

## 決定

- 画面の構成、操作、機能の振る舞いは Instagram を忠実に再現する。
- Instagram と Meta の名前・ロゴ・アイコン・フォント・画面写真・その他の素材は、製品にも docs にもテストの fixture にも入れない。アイコンと画像は独自に作るか、ライセンスが合う素材を使う。
- 製品名とロゴは独自にする。正式な名前は商標を調べてから決め、別の ADR に残す。それまでは作業名の `insta-modoki` と仮称を使う。
- code-reviewer はこの線引きを毎回確かめる。

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| UX は忠実、ブランドは独自（採用） | 学びとしての価値を保ち、権利の問題を避けられる | アイコンと素材を自前で用意する |
| 見た目もブランドも完全に複製する | 最も本物に近い | 商標・著作権の問題。public リポジトリには置けない |
| UX も独自にする | 権利の問題が最も小さい | 「忠実に模倣する」というユーザーの目的に合わない |

## 結果

- 再現の対象は振る舞いと情報の構成で、素材ではない。
- 素材を足す PBI は、出どころとライセンスを issue か commit に書く。
